# 070 反脆弱、凸性与非对称收益（Antifragility / Convexity）

课程页面：https://tanghuaizhe.github.io/mental-models-audit/course/070-antifragility-convexity/

## 何时调用

当波动、小冲击或试错可能带来净学习/净收益，或损失严格受限而潜在收益开放，需要判断收益曲线是否具有真正凸性时调用。

若它不会改变经营判断、风险判断、估值或下一步证据优先级，标记为 `Not material` 并停止展开。

## 审查问题

1. 收益函数对波动是凸、线性还是凹？更大的波动在期望上增加还是减少价值？
2. 下行是否真的被制度、合同、仓位或实验规模封顶？
3. 系统是否会从小失败中获得反馈、改进或筛选收益，而不是仅仅幸存？
4. 成功时是否能放大收益，失败时是否能快速止损？
5. 所谓‘反脆弱’是否只是普通分散、冗余或可选择性，被概念包装放大？

## 证据要求

- 优先引用公司、交易所、监管原始披露、可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称、类比或行业口号本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。
- 必须记录 `evidence_independence` 与 `incremental_information`，避免与邻近模型重复计票。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并注明来源/期间。
4. 明确底层机制，而不是只做类比。
5. 说明对收入、利润率、ROIC、竞争位置、资本需求、尾部风险、现金流或估值中的哪一项产生影响。
6. 给出最强反例或边界条件。
7. 写出至少一个可观察、尽量带时间/阈值的证伪条件。
8. 给出 0–100 的置信度。
9. 检查是否与其他模型共享同一证据或机制。
10. 推荐 0–3 个下一模型；若只是重复机制则不推荐。

优先联动：`033`、`027`、`098`。

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason，可省略其余字段。

## 边界

拥有选择权不等于反脆弱。分阶段投资由098处理；冗余与稳健性由027/065/069处理。本模型只有在收益对波动存在可验证的凸性时才Material。
