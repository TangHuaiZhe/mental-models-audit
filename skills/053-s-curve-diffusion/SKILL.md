# 053 S曲线与创新扩散

课程页面：https://tanghuaizhe.github.io/mental-models-audit/model-set-v1/053-s-curve-diffusion/

## 何时调用

当行业增长高度取决于渗透率、采用阶段、从早期用户向主流市场扩散或接近饱和时调用。

## 审查问题

1. 当前渗透率和潜在可服务市场是多少？
2. 增长主要来自新增采用者还是价格或份额变化？
3. 从早期采用者跨越到主流市场的关键约束是什么？
4. 什么领先指标表明扩散正在加速或接近饱和？
5. 不同地区或客户群是否处在不同S曲线阶段？

## 证据要求

- 优先引用公司、交易所、监管原始披露，可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并标记 evidence_id。
4. 明确底层机制，不做表面类比。
5. 说明它改变收入、利润率、ROIC、资本需求、竞争位置、尾部风险或估值中的哪一项。
6. 检查是否与其他模型共享同一事实；共享证据不得重复计权。
7. 给出最强反例或边界条件。
8. 写出至少一个可观察的证伪条件。
9. 给出0–100置信度，并说明是否增加独立机制/独立证据/新行动。
10. 优先联动：039 复利、043 供需、073 延迟、093 冲击与结构

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason。

## 边界

S曲线不是把任何高增长画成S形。必须能定义采用单位、潜在市场和渗透率；周期波动优先093，份额竞争优先043/095。
