# 057 资本周期

课程页面：https://tanghuaizhe.github.io/mental-models-audit/model-set-v1/057-capital-cycle/

## 何时调用

当行业高利润或高预期回报正在吸引CAPEX、新进入者和产能扩张，并且供给建设具有时间延迟时调用。

## 审查问题

1. 当前行业ROIC/利润率是否显著高于资本成本并吸引新增资本？
2. 在建产能、新进入者和融资规模多大，何时形成有效供给？
3. 需求增速能否吸收新增供给？
4. 资本进入将通过价格、利用率、份额还是成本改变未来ROIC？
5. 低回报阶段是否会触发退出、减产和下一轮供给收缩？

## 证据要求

- 优先引用公司、交易所、监管原始披露，可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并标记 evidence_id。
4. 明确底层机制，不做表面类比。
5. 说明它改变收入、利润率、ROIC、资本需求、竞争位置、尾部风险或估值中的哪一项。
6. 检查是否与其他模型共享同一事实；共享证据不得重复计权。
7. 给出最强反例或边界条件。
8. 写出至少一个可观察的证伪条件。
9. 给出0–100置信度，并说明是否增加独立机制/独立证据/新行动。
10. 优先联动：043 供需、066 军备竞赛、073 延迟、093 周期与结构

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason。

## 边界

043供需描述当期均衡；066军备竞赛描述竞争者被迫投入；057专门描述利润→资本进入→供给→回报率的跨周期反馈。
