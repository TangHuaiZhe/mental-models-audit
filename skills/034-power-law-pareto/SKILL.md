# 034 幂律与帕累托分布（Power Law / Pareto Distribution）

课程页面：https://tanghuaizhe.github.io/mental-models-audit/course/034-power-law-pareto/

## 何时调用

当少数客户、产品、药物、项目、渠道、风险事件或创作者贡献大部分结果，平均值可能严重误导时调用。

若它不会改变经营判断、风险判断、估值或下一步证据优先级，标记为 `Not material` 并停止展开。

## 审查问题

1. 结果分布是否高度右偏，Top 1/5/10 项贡献了多少收入、利润、价值或风险？
2. 均值和中位数差异有多大？典型样本是否被少数极端值掩盖？
3. 如果最大贡献项失败，组合价值会下降多少？
4. 组合是否通过增加独立下注提高了捕获极端赢家的概率，还是只是制造更多低质量项目？
5. 未来分布是否可能从幂律变得更均匀，或反过来更加集中？

## 证据要求

- 优先引用公司、交易所、监管原始披露、可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称、类比或行业口号本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。
- 必须记录 `evidence_independence` 与 `incremental_information`，避免与邻近模型重复计票。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并注明来源/期间。
4. 明确底层机制，而不是只做类比。
5. 说明对收入、利润率、ROIC、竞争位置、资本需求、尾部风险、现金流或估值中的哪一项产生影响。
6. 给出最强反例或边界条件。
7. 写出至少一个可观察、尽量带时间/阈值的证伪条件。
8. 给出 0–100 的置信度。
9. 检查是否与其他模型共享同一证据或机制。
10. 推荐 0–3 个下一模型；若只是重复机制则不推荐。

优先联动：`033`、`040`、`032`。

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason，可省略其余字段。

## 边界

不要仅因为“80/20”听起来熟悉就判定幂律。需要真实集中度、尾部分布或 winner-take-most 机制证据；普通波动优先033。
