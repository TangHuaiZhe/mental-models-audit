# 091 期限转换与久期缺口

课程页面：https://tanghuaizhe.github.io/mental-models-audit/model-set-v1/091-maturity-transformation-duration-gap/

## 何时调用

当银行、保险、REIT、地产或高杠杆企业的资产与负债在期限、流动性或利率重定价速度上不匹配时调用。

## 审查问题

1. 资产与负债的合同期限、有效久期和重定价周期分别是多少？
2. 短期或可赎回负债支持多少长期或低流动性资产？
3. 利率变化时，资产收益率与负债成本谁先重定价？
4. 在挤兑、融资收紧或抵押品折价情景下，流动性缺口多大？
5. 管理层用对冲、存款结构、资本缓冲或期限匹配降低了多少风险？

## 证据要求

- 优先引用公司、交易所、监管原始披露，可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并标记 evidence_id。
4. 明确底层机制，不做表面类比。
5. 说明它改变收入、利润率、ROIC、资本需求、竞争位置、尾部风险或估值中的哪一项。
6. 检查是否与其他模型共享同一事实；共享证据不得重复计权。
7. 给出最强反例或边界条件。
8. 写出至少一个可观察的证伪条件。
9. 给出0–100置信度，并说明是否增加独立机制/独立证据/新行动。
10. 优先联动：024 杠杆、033 尾部风险、075 存量流量、097 压力测试

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason。

## 边界

一般杠杆不等于期限转换。只有资产负债期限或重定价错配改变NIM、流动性或资本稳定性时才Material。
