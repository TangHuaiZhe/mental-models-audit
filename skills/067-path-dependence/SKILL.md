# 067 路径依赖与锁定（Path Dependence & Lock-in）

课程页面：https://tanghuaizhe.github.io/mental-models-audit/course/067-path-dependence-lock-in/

## 何时调用

当当前技术、组织、标准或制度是历史选择累积的结果，并通过学习效应、互补资产、切换成本或利益集团形成自我强化锁定时调用。

若它不会改变经营判断、风险判断、估值或下一步证据优先级，标记为 `Not material` 并停止展开。

## 审查问题

1. 当前结构中哪些关键选择来自历史偶然或早期先发，而不是今天从零设计的最优方案？
2. 学习效应、互补资产、标准、用户习惯、合同或利益集团如何强化旧路径？
3. 锁定给公司带来护城河，还是同时制造技术债、组织惯性或制度成本？
4. 什么冲击、技术跃迁或临界窗口足以打破锁定？
5. 如果今天从零开始，理性参与者还会选择同一路径吗？

## 证据要求

- 优先引用公司、交易所、监管原始披露、可靠结构化财务数据、行业一手数据或可复核事实。
- 区分：已披露事实 / 外部证据 / 分析判断 / 前瞻假设。
- 不允许用模型名称、类比或行业口号本身充当证据。
- 关键事实缺失时写入 `unknowns`，不要补故事。
- 必须记录 `evidence_independence` 与 `incremental_information`，避免与邻近模型重复计票。

## 执行步骤

1. 给出相关性：`Material | Secondary | Not material`。
2. 写出本模型试图回答的唯一核心问题。
3. 分列支持与反对证据，并注明来源/期间。
4. 明确底层机制，而不是只做类比。
5. 说明对收入、利润率、ROIC、竞争位置、资本需求、尾部风险、现金流或估值中的哪一项产生影响。
6. 给出最强反例或边界条件。
7. 写出至少一个可观察、尽量带时间/阈值的证伪条件。
8. 给出 0–100 的置信度。
9. 检查是否与其他模型共享同一证据或机制。
10. 推荐 0–3 个下一模型；若只是重复机制则不推荐。

优先联动：`048`、`088`、`092`。

## 输出

严格遵循 `../../schema/audit-output.yaml`。若为 `Not material`，只输出 model、relevance、reason，可省略其余字段。

## 边界

v1.0 已吸收旧091‘制度路径依赖’。不要把任何历史事实都叫路径依赖；必须存在明确的自我强化与切换成本。
