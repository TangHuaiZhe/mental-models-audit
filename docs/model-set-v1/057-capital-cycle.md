# 057｜资本周期

> **Model Set v1.0 新增/修订模型。** GitHub版本是当前 active audit 规范；被替换的旧《跨学科思维模型100讲》页面仍保留为 legacy。

## 一句话定义

高利润吸引资本进入，新增供给经过延迟形成后压低价格和回报；低回报又促使资本退出，形成跨周期反馈。

## 核心机制

利润信号改变CAPEX和新进入，供给建设有时滞，因此行业ROIC往往在资本最乐观时接近未来拐点。

## 典型应用

- 晶圆厂扩产。
- 电池产能周期。
- AI数据中心资本开支。
