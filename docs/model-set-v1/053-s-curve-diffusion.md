# 053｜S曲线与创新扩散

> **Model Set v1.0 新增/修订模型。** GitHub版本是当前 active audit 规范；被替换的旧《跨学科思维模型100讲》页面仍保留为 legacy。

## 一句话定义

新技术采用通常经历早期缓慢、加速扩散、最后接近饱和的S形路径。

## 核心机制

采用受成本、基础设施、社会证明、兼容性和边际用户价值影响；不同阶段对应完全不同的增长弹性。

## 典型应用

- 储能渗透率。
- AI Agent基础设施采用。
- 新能源汽车从早期用户走向主流市场。
