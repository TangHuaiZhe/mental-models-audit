# 100 Model Set v1.0

这是基于多个商业 archetype 回归测试后形成的 active 100 模型集合。

## 原则

- 100个模型是 blind-spot checklist，不是100票。
- 优先保留独立机制、独立证据与独立决策变量。
- Legacy课程不删除；Router只读取active registry。
- 新增模型来自真实公司分析中反复出现的缺口。
