# 070｜反脆弱、凸性与非对称收益

> **Model Set v1.0 新增/修订模型。** GitHub版本是当前 active audit 规范；被替换的旧《跨学科思维模型100讲》页面仍保留为 legacy。

## 一句话定义

当收益函数对波动呈凸性时，系统不仅能承受波动，还可能从不确定性中提高期望收益。

## 核心机制

有限下行与开放上行形成非对称收益；关键是收益函数的形状，而不是简单“有备用方案”。

## 典型应用

- 小损失频繁试验换取极端上行。
- 具有凸性收益的资产或商业结构。
- 压力暴露弱点并触发可复用学习。
