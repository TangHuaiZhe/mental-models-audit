# 015｜古德哈特定律

> **Model Set v1.0 新增/修订模型。** GitHub版本是当前 active audit 规范；被替换的旧《跨学科思维模型100讲》页面仍保留为 legacy。

## 一句话定义

当一个代理指标成为优化目标，它往往会逐渐失去作为真实目标代理的可靠性。

## 核心机制

参与者会对考核规则做策略性适应，把努力投入到“提高指标”而非“改善真实结果”，从而形成指标与目标的系统性背离。

## 典型应用

- 茅台渠道压货：出货KPI改善但渠道库存和价格体系恶化。
- 互联网增长：MAU上涨但留存、付费或单位经济变差。
- AI benchmark：模型针对测试集优化而非真实任务能力。

## 审计纪律

- 模型名称不是证据。
- Material 必须给出独立证据、机制、边界和证伪条件。
- 与其他模型共享同一事实时不得重复计权。
- 先区分 business / company / industry / security / share_class / trading_counter / policy / strategy / analyst_self。
