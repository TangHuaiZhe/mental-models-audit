# 第015讲：古德哈特定律（Goodhart's Law）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

当一个代理指标变成被直接优化的目标，它往往会逐渐失去衡量真实目标的能力。

## 一、起源与学科背景

查尔斯·古德哈特在讨论货币管理时提出：原本用于观察经济的统计规律，一旦成为控制目标，可靠性就会下降。这是测量理论、激励理论与控制论的交叉问题。其重点并非“所有指标都无用”，而是**治理动作改变了被测对象**。

## 二、核心机制

设真实目标为顾客长期价值，代理指标为当期销量。管理层按销量奖惩销售团队后，团队可以通过真实需求增长、提前出货或渠道压货三条路径提高销量。只有第一条同时改善目标。指标与目标的原有相关性在奖惩后可能被人为选择破坏。检验时要比较指标上升与退货、库存、复购等结果指标是否同向。

## 三、经典案例：逐步拆解

**教学假设：渠道压货。**某品牌把季度出货量作为奖金依据。季末经销商收到大量货，报表销量增长；终端零售没有同步增长，渠道库存天数和次季退货率上升。第一步先识别“真实目标＝最终消费者需求”；第二步找“代理＝对经销商出货”；第三步查奖励和时间窗；第四步找终端零售与库存作反证。单凭季度出货上升不能证明造假，也可能是季节性备货。

## 四、跨领域迁移

**软件产品：**日活跃用户数可能被无价值的通知点击推高，需对照留存与有效使用。**医疗管理：**若只奖励就诊量，可能挤压每次诊疗质量；要观察患者结果与病例复杂度。两个领域共同点都是可计数代理被奖惩放大，差别在于真实结果的测量周期。

## 五、何时调用与分析步骤

发现指标突然改善、奖金阈值附近异常集中、短期冲量或核心结果滞后时调用。依次写明真实目标、代理、受激励者、可操纵途径和独立结果指标；用同口径前后数据与未被考核的对照组核验。若没有可识别代理及行为改变，退出本模型。

## 六、边界、误用与反例

指标改善与真实结果同步、且独立测量可信时，不能因存在考核就断言失真。销量增长也可能源自真实需求。044「委托代理」回答谁有何激励；015 专门审查代理失真；079「可观测性」讨论能否看见系统状态。不要把所有绩效问题都归给古德哈特定律。

## 七、与其他模型的连接

[044 激励与委托代理](044-incentive-principal-agent.md)解释奖励安排；[079 可观测性与可控性](079-observability-controllability.md)帮助寻找独立结果指标；[072 反馈](072-feedback-loops.md)解释考核如何反过来改变行为。

## 八、五个关键自问

1. 真实目标是什么，谁定义它？
2. 当前指标只是目标的哪一部分？
3. 谁会因指标变化获得利益？
4. 哪些不改善目标的动作也能提高指标？
5. 哪个独立结果能让我改变判断？

## 九、思考练习

选择一项公开披露的增长指标，画出“真实目标—代理—奖励—行为—结果”的链条。列出至少两种可能解释，并指定一个能够区分它们的观测量。

## 十、自测题

**题目：**客服接通率上升，但投诉复发率也上升。能直接判定团队操纵指标吗？

**参考思路：**不能。先核对分母、来电结构及接通定义，再看是否出现匆忙挂断等可提高接通率而不解决问题的行为；若有奖励绑定和独立结果背离，才形成较强的古德哈特机制证据。

## 十一、Evolution（版本演化）

先识别目标与代理；再画激励链；再寻找独立结果；最后设计成对指标与反作弊检验。本次课程扩充教学说明，Model Set 仍为 v1.0。

## 研究与决策核对

**最小证据包：**①考核制度及生效日期；②代理指标的原始定义和分母；③未被同一考核绑定的终端结果；④受考核者的可控动作。若只取得公开报表中的代理指标，结论应标为待核实的机制假设，不能指控造假。分析时优先比较制度改变前后，并控制季节性及行业共同冲击。

**可证伪预测：**如果真实需求驱动增长，终端销售、复购和渠道库存周转应在合理滞后内同步改善；如果只有出货在奖金结算前跳升，代理偏离更值得调查。即使出现背离，还应查产品发布或渠道扩张等替代解释。
