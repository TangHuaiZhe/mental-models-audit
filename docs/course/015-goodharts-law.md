# 第015讲：古德哈特定律（Goodhart's Law）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

当一个代理指标变成被直接优化的目标，它往往会逐渐失去衡量真实目标的能力。

## 核心机制

组织使用KPI、销量、增长率、转化率或风险指标做代理；一旦奖励与代理指标绑定，参与者会优化指标本身，甚至牺牲真实目标。

## 为什么它对公司与行业研究重要

它能解释渠道压货、虚假活跃度、短期利润优化、风险模型套利等问题，比一般激励模型更强调“真实目标—代理指标—游戏化”的链条。

## 典型应用

- 消费品销售目标导致渠道库存堆积
- 互联网团队追求DAU而制造低质量互动
- 监管指标诱发资产结构套利

## 什么时候调用

- 真实目标和代理指标分别是什么？
- 谁因这个指标获得奖励或惩罚？
- 能否提高指标却不改善真实结果？
- 指标成为目标后行为发生了什么变化？
- 什么替代指标更接近真实目标？

## 适用边界与常见误用

没有明确代理指标时不要强套；一般激励问题用044，可观测性问题用079。

## 与其他模型的连接

- 044 激励相容与委托代理
- 079 可观测性与可控性
- 072 正反馈与负反馈

## 五个关键自问

1. 真实目标和代理指标分别是什么？
2. 谁因这个指标获得奖励或惩罚？
3. 能否提高指标却不改善真实结果？
4. 指标成为目标后行为发生了什么变化？
5. 什么替代指标更接近真实目标？
