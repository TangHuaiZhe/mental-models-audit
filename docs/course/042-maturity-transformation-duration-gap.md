# 第042讲：期限转换与久期缺口（Maturity Transformation / Duration Gap）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

资产和负债的期限、重定价速度或流动性承诺不一致时，利率变化会通过时间错配放大利润与风险。

## 一、起源与学科背景

期限转换是银行金融中“短期可兑付负债支持长期资产”的基本结构；资产负债管理进一步用重定价缺口和久期衡量利率暴露。它是金融中介提供流动性的一部分，也会在利率冲击与提款压力下暴露风险。

## 二、核心机制

区分三条链：① **收入链**：负债先重定价、资产后重定价，净利息收入可能收窄；② **估值链**：利率上升时长久期固定利率资产价格下降，近似 $\Delta P/P\approx-D\Delta y$（仅小幅平行变动近似）；③ **流动性链**：若提款迫使出售资产，未实现估值损失会变成已实现损失。三者相关但不能混为一谈。

## 三、经典案例：逐步拆解

**教学假设：银行持有长期固定利率债券。**资产市值 100、修正久期 5，利率上升 1 个百分点时，粗略估计价格下跌约 5；若对应负债久期接近零，净值承压。若存款稳定且有足够现金和对冲，未必需要立刻出售；若集中提款超过流动性缓冲，损失可能兑现。这个数字只是久期一阶近似，未含凸性、信用与存款行为。

## 四、跨领域迁移

**保险：**未来赔付义务长，资产期限过短也会形成反向再投资风险。**高负债企业：**长期固定收入配短期浮息借款，利息成本先涨、收入后调。两者都要画现金流时间表，但保险负债和企业借款的可提款性不同。

## 五、何时调用与分析步骤

利率快速变动、存款竞争、再融资集中到期、资产负债期限不一致时调用。分别列资产与负债的合同期限、实际重定价日、提前偿还/提款选项；做 ±100 基点收入与估值敏感性，再叠加现金流压力情景。

## 六、边界、误用与反例

久期相同也可能因现金流时点、非平行收益率曲线、信用风险或提款行为而损失；高杠杆本身不等于期限错配。反例：长期固定利率资产由期限相近的固定负债融资且有充分流动性缓冲，利率上升未必造成急售。

## 七、与其他模型的连接

[024 杠杆](024-leverage.md)解释净值对资产变化的放大；[033 尾部风险](033-variance-tail-risk.md)覆盖压力情景；[075 存量—流量动力学](075-stock-flow-dynamics.md)区分资产存量与当期现金流。

## 八、五个关键自问

1. 资产和负债分别何时重定价、何时可兑付？
2. 利率变化先影响净息差还是净值？
3. 负债持有人实际会如何提款或续存？
4. 压力下可用现金、抵押融资和对冲有多少？
5. 哪一种情景会把账面损失变成现金损失？

## 九、思考练习

用久期近似估算：100 元固定债券、修正久期 5，利率上升 0.5 个百分点。再讨论若 20 元负债立即到期，为什么估值损失和现金缺口必须分开分析。

## 十、自测题

**题目：**一家银行债券账面浮亏就等于马上破产吗？

**参考思路：**不等于。还要看资本口径、负债稳定性、流动性、对冲以及是否必须出售；浮亏也不能被简单忽略。

## 十一、Evolution（版本演化）

先画到期与重定价时间线；再分解净息差、净值和现金流；再做提款与利率联合压力测试。课程内容升级，Model Set v1.0 不变。

## 研究与决策核对

**最小证据包：**资产与负债的合同到期表、实际重定价表、存款集中度、可用现金、抵押融资能力、对冲头寸和压力情景。净息差（NIM）是一个期间的收益指标；久期近似关注资产市值变化；流动性缺口关注现金是否按时到位。三张表需要同一利率冲击假设，但不能互相替代。

**进一步推演：**上文 100 元债券、久期 5 的例子，若利率上升 0.5 个百分点，一阶估值约降 2.5 元。若 20 元负债此时到期且没有现金，是否能抵押融资、以什么折价出售，才决定损失是否立即兑现；不能用 2.5 元直接等同于提款缺口。
