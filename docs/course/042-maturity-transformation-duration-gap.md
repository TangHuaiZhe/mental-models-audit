# 第042讲：期限转换与久期缺口（Maturity Transformation / Duration Gap）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

资产和负债的期限、重定价速度或流动性承诺不一致时，利率变化会通过时间错配放大利润与风险。

## 核心机制

银行常用短期、低成本、可提款负债支持长期贷款/债券；资产与负债利率并不同步重定价，压力时账面久期差异还可能变成真实流动性损失。

## 为什么它对公司与行业研究重要

这是银行、保险、REIT和高负债企业分析的基础机制，可解释NIM、存款竞争和流动性风险。

## 典型应用

- 存款成本先升而贷款尚未重定价导致NIM收窄
- 长期债券面对提款压力被迫亏损出售
- 固定资产收益与浮动负债成本形成错配

## 什么时候调用

- 资产和负债多久重定价？
- 利率±100bp谁先变化？
- 多少短期负债支持长期资产？
- 压力下需要出售哪些资产？
- 资本与流动性缓冲够不够？

## 适用边界与常见误用

杠杆高不等于久期缺口；必须存在期限、重定价或流动性不匹配。
