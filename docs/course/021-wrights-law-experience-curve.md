# 第021讲：赖特定律与经验曲线（Wright's Law / Experience Curve）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

累计生产经验增加时，单位成本、良率和周期时间往往沿学习曲线持续改善。

## 核心机制

重复制造积累缺陷数据、工艺诀窍、自动化方法和供应链优化。它不同于固定成本摊薄：真正驱动变量是累计经验。

## 为什么它对公司与行业研究重要

对半导体、电池、光伏、机器人等先进制造尤其重要，可以把先发优势转成可验证的累计产量—成本/良率关系。

## 典型应用

- 先进制程晶圆累计量提升带来良率改善
- 动力电池累计GWh扩大后单位Wh成本下降
- 工业设备部署次数增加后安装周期缩短

## 什么时候调用

- 累计产量每翻倍，成本或良率如何变化？
- 改善中多少来自学习而非规模？
- 学习能否跨工厂/代际迁移？
- 是否接近工艺极限？
- 竞争者能否快速复制经验？

## 适用边界与常见误用

原材料降价、采购折扣或固定成本摊薄不属于Wright's Law；技术代际切换还可能重置学习。
