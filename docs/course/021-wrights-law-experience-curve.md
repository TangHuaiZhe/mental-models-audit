# 第021讲：赖特定律与经验曲线（Wright's Law / Experience Curve）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

累计生产经验增加时，单位成本、良率和周期时间往往沿学习曲线持续改善。

## 一、起源与学科背景

西奥多·赖特在 1936 年分析飞机制造成本，观察到生产经验累积与单位工时下降的关系。后来制造业把这种规律发展为经验曲线。它是经验关系，不是保证每次翻倍都降本的自然定律。

## 二、核心机制

令累计产量为 Q，单位成本为 C，可用教学近似式 $C(Q)=C_0(Q/Q_0)^b$，其中 $b<0$。若每翻倍成本变为原来的 80%，学习率为 20%；从 100 元降到 80 元，再翻倍为 64 元。机制可能包括工序优化、缺陷反馈、工人熟练、设备调校；需要用同产品、同成本口径检验。产量翻倍是累计而非当年产量翻倍。

## 三、经典案例：逐步拆解

**经典背景：飞机制造。**早期批次需要摸索工装、装配顺序和质检，后续批次复用经验，单位工时下降。若只看到总成本降低，仍需排除零件规格变更、材料降价和固定成本摊薄。用批次累计交付量对照可比单位工时，才接近赖特所研究的现象。

## 四、跨领域迁移

**电池制造：**记录累计电芯产量与可比良率、单位制造工时；材料价格另列。**软件交付：**重复部署积累脚本与故障知识，单位部署时间可下降，但产品差异太大时不能生搬硬套同一斜率。两个领域共享重复—反馈—改进链条，学习能否跨代际转移需单独证明。

## 五、何时调用与分析步骤

适用于高重复度、可测单位产出、存在累计批次数据的活动。先固定产品定义与成本口径，再画累计量与单位成本的对数关系，检查每次翻倍的斜率是否稳定；同时分解原料、采购、规模摊销与经验贡献。新技术代际出现时重新估计。

## 六、边界、误用与反例

大宗原料跌价、折旧分摊、产品降配都可能造成表面降本。反例是累计产量增加但关键工序良率触顶、原料稀缺导致成本上升。046 讨论当期产量和共享资源带来的规模/范围经济；021 讨论跨时间累积经验。

## 七、与其他模型的连接

[046 规模与范围经济](046-economies-of-scale-scope.md)区分当期产量效应；[029 瓶颈](029-bottleneck-toc.md)定位学习难以传递的工序；[099 反馈与迭代学习](099-feedback-learning-speed.md)解释改进速度。

## 八、五个关键自问

1. 累计量的定义和单位成本口径是否稳定？
2. 每翻倍的可比成本变化是多少？
3. 降本有多少来自经验而非材料和固定成本？
4. 经验能否跨工厂、产品代际迁移？
5. 什么证据说明曲线变平或重置？

## 九、思考练习

假设某工艺累计产量从 1 万增至 2 万、4 万件，可比单位成本为 100、82、68 元。分别计算两次翻倍的降幅；判断能否直接外推至 8 万件，并列出两项需要控制的变量。

## 十、自测题

**题目：**某企业当年产量翻倍，单位成本下降 15%，这足以证明赖特定律吗？

**参考思路：**不足。要看累计产量、产品同质性与成本构成；当年规模提升可能只摊薄固定成本。

## 十一、Evolution（版本演化）

先区分累计与当期产量；再按可比口径估斜率；再做成本桥与代际分段；最后用区间而非机械外推制定情景。本次仅扩充课程，模型集合版本不变。

## 研究与决策核对

**最小证据包：**按相同规格统计的累计交付量、单位制造成本或工时、良率、材料采购价与产能利用率。把每一轮“累计量翻倍”分开计算，观察是否稳定；若产线改造或产品换代，标出断点而不是用一条线穿过所有数据。

**可证伪预测：**如果学习是主因，同一工艺的重复批次应在控制材料价格和当期规模后仍表现出可比工时或缺陷率下降；若降本完全由原材料价格解释，经验曲线不是主要机制。前述 100→80→64 元只是教学演算，不是行业通用参数。
