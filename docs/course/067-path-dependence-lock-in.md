# 第067讲：路径依赖与锁定（Path Dependence & Lock-in）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

早期选择通过学习效应、互补资产、标准、切换成本和利益集团形成自我强化，使系统难以自由切换路径。

## 核心机制

关键不是“发生得早”，而是选择之后出现自我强化：技能、资产、制度和参与者都围绕旧路径积累。

## 为什么它对公司与行业研究重要

它既解释护城河，也解释组织惯性、技术债和制度改革困难。v1.0合并旧067与旧091。

## 典型应用

- 软件标准因生态兼容长期锁定
- 企业IT架构因历史系统难以重构
- 制度因配套规则和既得利益难改变

## 什么时候调用

- 哪些结构来自早期历史选择？
- 什么机制让旧路径越走越稳？
- 锁定带来优势还是负担？
- 什么冲击能打破锁定？
- 今天从零开始还会选同一路径吗？

## 适用边界与常见误用

没有自我强化或切换成本时不构成强路径依赖。
