# 第067讲：路径依赖与锁定（Path Dependence & Lock-in）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

早期选择通过学习效应、互补资产、标准、切换成本和利益集团形成自我强化，使系统难以自由切换路径。

## 一、起源与学科背景

路径依赖来自经济史和技术采用研究。布赖恩·阿瑟研究在采用收益递增时，早期事件如何影响技术竞争的最终结果。当前课程把技术标准、组织能力和制度安排放在同一分析框架，但不能把任何历史延续都叫锁定。

## 二、核心机制

初始选择 A 后，培训、设备、接口与用户习惯围绕 A 投入；A 的采用者越多，兼容工具越多，后来者转向 B 的成本越高。链条是“早期选择→互补投入→采用收益递增/转换成本→路径持续”。锁定可能保护高效标准，也可能保留低效方案。要分别比较沿旧路与切换新路的全成本。

## 三、经典案例：逐步拆解

**经典机制：竞争技术标准。**假设两个接口性能相近，A 早期获得小幅采用领先，开发者因用户多而先做 A 的插件；新用户又因插件多而选择 A。若后来 B 的独立性能更好，仍可能难以切换。这里不能仅凭 A 占优推断 B 更优；必须同时证明早期偶然事件、采用收益递增和替代方案的净优势。

## 四、跨领域迁移

**企业软件：**历史数据库、接口和人员技能形成迁移成本，可用试点迁移验证。**制度改革：**既有法规、预算和受益群体共同维持政策路径，需要看法律权限与补偿机制。两领域都存在互补投入，但制度路径还受权力分配影响；091 的资本周期则讨论行业供给，不是同一机制。

## 五、何时调用与分析步骤

当前方案看似不佳却长期维持、标准高度集中或迁移成本争议大时调用。先追溯关键选择时点，再列互补资产、网络效应、培训与规则；估算继续与切换的全生命周期成本，寻找低成本局部试点。没有自我强化证据时退出。

## 六、边界、误用与反例

长期存在可能仅因为方案仍然优越；切换也可能因监管禁止而非历史锁定。反例是开放接口使新旧系统低成本互通，旧标准占优但无强切换壁垒。不能把“时间过去了”当作路径依赖的证据。

## 七、与其他模型的连接

[047 网络效应](047-network-effects.md)解释采用者之间的价值反馈；[048 交易成本](048-transaction-costs.md)量化转换障碍；[092 临界转折](092-critical-juncture.md)讨论改变路径的窗口。

## 八、五个关键自问

1. 哪次早期选择决定了当前路径？
2. 哪些互补投入使后续选择不再独立？
3. 继续和切换各有什么完整成本？
4. 当前路径是有效率还是仅有惯性？
5. 什么冲击或试点会改变锁定强度？

## 九、思考练习

选一个组织使用超过五年的系统，列出可观察的锁定证据和“它仍然最好”的竞争解释；设计一个小范围迁移试验来区分两者。

## 十、自测题

**题目：**某软件市场份额第一维持十年，能断言存在低效锁定吗？

**参考思路：**不能。还需证明早期事件、收益递增或转换成本，以及替代方案在全成本下更优。

## 十一、Evolution（版本演化）

先追溯历史选择；再找自我强化；再比较替代方案与转换成本；最后寻找可逆试点与转折窗口。v1.0 的 067 吸收历史课程的相关讨论，本次只补教材正文。

## 研究与决策核对

**最小证据包：**早期选择的时间线、后续互补投入、切换成本明细、替代方案全成本与部分迁移的试点结果。把历史沉没成本与未来转换成本分开：前者已经发生，不应单独阻止更换；后者仍会影响今天的最优选择。

**双向判断：**路径依赖既可能带来护城河，也可能形成组织负担。若旧标准的兼容生态给客户的增量价值超过切换成本，持续采用可能是理性选择。只有看到“替代方案净收益更高，却因自我强化和协调失败而难以迁移”，才有较强的低效锁定判断。
