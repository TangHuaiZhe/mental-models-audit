# 第053讲：S曲线与创新扩散（S-Curve / Diffusion of Innovation）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

新技术或产品采用通常经历导入、加速、成熟和饱和，而不是永远保持同一增长率。

## 核心机制

早期扩散受成本、可靠性、基础设施和认知限制；跨过关键阈值后加速；接近终局渗透率时新增采用者自然减少。

## 为什么它对公司与行业研究重要

它能避免把新能源、储能、AI产品、云服务的当前高增长率机械外推。

## 典型应用

- 储能渗透率进入加速期
- 开发者平台跨越到主流采用
- 成熟智能手机市场自然放缓

## 什么时候调用

- 潜在采用者/终局渗透率是多少？
- 当前处于哪个扩散阶段？
- 增长来自采用还是价格/份额？
- 跨越下一阶段的约束是什么？
- 什么指标最早显示拐点？

## 适用边界与常见误用

没有可定义的采用者基数或终局渗透率时不要强套；价格周期和份额转移不是扩散曲线。
