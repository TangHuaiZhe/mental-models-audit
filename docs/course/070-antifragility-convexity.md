# 第070讲：反脆弱、凸性与非对称收益（Antifragility / Convexity）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

真正的反脆弱是收益函数对波动具有凸性：小损失受限，而波动、试错或少数成功能带来更大的上行。

## 核心机制

凸性来自非对称收益或从小失败中获得可利用的信息。它不同于简单冗余，也不同于拥有分阶段选择权。

## 为什么它对公司与行业研究重要

用于判断研发组合、小实验、仓位和组织学习是否真正从不确定性中获益。

## 典型应用

- 多个小实验失败成本固定但成功可规模化
- 小仓位下行有限、上行开放
- 模块化系统从局部失败中学习

## 什么时候调用

- 收益对波动是凸还是凹？
- 下行是否真正封顶？
- 小失败是否产生学习？
- 成功能否迅速放大？
- 所谓反脆弱是否只是冗余/选择权？

## 适用边界与常见误用

v1.0把Optionality交给098；可停止项目不等于反脆弱，冗余也只是稳健。
