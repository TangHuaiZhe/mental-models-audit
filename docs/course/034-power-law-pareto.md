# 第034讲：幂律与帕累托分布（Power Law / Pareto Distribution）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

少数极端结果可能贡献大部分总价值、收入或风险，平均值并不能代表典型样本。

## 一、起源与学科背景

帕累托分布最早用于描述高度不均的财富分布；后来的统计学与复杂系统研究把幂律用于多种尾部现象。帕累托观察并不意味着所有行业都固定遵循“80/20”。关键问题是尾部有多厚、样本是否足以区分其他分布。

## 二、核心机制

在某一阈值以上，若尾部近似满足 $P(X>x)\propto x^{-\alpha}$，极大值出现的机会比薄尾分布更高。正反馈、优先连接和可扩展复制可能生成集中度，但“分布像幂律”本身不证明是哪一种机制。小样本下，均值容易被头部样本拖动；应同时报告中位数、前 1/5/10 项贡献和集中度随时间的变化。

## 三、经典案例：逐步拆解

**教学假设：风险投资组合。**20 个项目中 15 个亏损、4 个小幅盈利、1 个回报 30 倍。若单项最大损失限定为投入本金，头部赢家可能决定总回报；只看项目成功率会误判组合。不过这组假设数据不能证明总体服从严格幂律，必须看更多基金、年份和尾部拟合。

## 四、跨领域迁移

**平台经济：**少数创作者可能获得大部分浏览，但算法分发、身份优势与供给质量都可能解释集中。**供应链：**少数客户占大部分收入，使单客流失成为尾部风险。前者关心上行集中，后者关心下行集中；不能把客户依赖自动称作正反馈。

## 五、何时调用与分析步骤

当均值明显高于中位数、头部项目决定组合、或单客敞口很大时调用。先确定观测单位、时间窗和截断阈值，展示排序图与头部贡献；再和对数正态等重尾候选比较。样本过少时仅称“集中”或“厚尾风险”，避免拟合结论。

## 六、边界、误用与反例

80/20 是比例描述，不是分布检验；正态分布的有限样本也可能出现明显头部。对受上限约束的市场，尾部不可能无限延伸。033 讨论尾部损失与波动；034 讨论横截面贡献的集中结构；040 再讨论多项之间的相关性。

## 七、与其他模型的连接

[033 方差与尾部风险](033-variance-tail-risk.md)处理极端损失；[040 协方差与分散化](040-covariance-diversification.md)检查组合是否真正独立；[032 期望值](032-expected-value.md)计算集中收益对决策的影响。

## 八、五个关键自问

1. 观察单位、样本窗口和分母是什么？
2. 前 1/5/10 项贡献多少，均值和中位数相差多少？
3. 尾部能否与其他重尾分布区分？
4. 头部集中是如何生成的，能否持续？
5. 最大项消失或失败时结论如何变？

## 九、思考练习

把某公司 10 个客户的收入从高到低排列，算前两名占比、均值与中位数，并做“最大客户流失”情景。写明这只证明集中度还是足以证明幂律。

## 十、自测题

**题目：**某产品 20% 的用户贡献 80% 收入，可以断言收入服从帕累托幂律吗？

**参考思路：**不能。一个分位点不能识别整段尾部分布；还需要更完整的排序数据、阈值和与其他候选分布的比较。

## 十一、Evolution（版本演化）

先承认集中现象；再量化头部与尾部；再检验机制和替代分布；最后把最大项情景纳入组合决策。扩充课程不改变 Model Set v1.0。

## 研究与决策核对

**最小证据包：**完整样本而非只列赢家；统一起始投入和观察期；排序后的贡献、最大值、中位数及样本数。若讨论投资组合，还要看单项损失上限与项目之间的相关性。对统计拟合，应明确尾部阈值、估计方法及其他重尾分布的竞争性解释。

**决策含义：**当少数赢家决定总收益时，过早卖出赢家、或因多数项目失败就停止全部试验，可能损害组合；当少数客户决定总收入时，风险控制则相反，需限制集中度。相同的集中形态不自动给出相同策略。
