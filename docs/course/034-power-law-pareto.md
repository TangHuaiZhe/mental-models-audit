# 第034讲：幂律与帕累托分布（Power Law / Pareto Distribution）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

少数极端结果可能贡献大部分总价值、收入或风险，平均值并不能代表典型样本。

## 核心机制

正反馈、累积优势、网络结构或高失败率创新会形成长尾：大量普通结果，加上极少数超级赢家。

## 为什么它对公司与行业研究重要

创新药、平台、VC、客户集中和产品组合都可能呈幂律，它会改变组合设计和估值方法。

## 典型应用

- 一个blockbuster药物贡献公司大部分价值
- 少数大客户贡献多数收入
- 少数创作者占平台多数交易

## 什么时候调用

- Top 1/5/10贡献多少结果？
- 均值与中位数差多大？
- 最大项失败损失多少？
- 更多独立下注是否提高抓到赢家的概率？
- 未来分布会更集中还是更均匀？

## 适用边界与常见误用

不能把所有80/20都叫幂律；需要真实集中度、尾部或winner-take-most机制证据。

## 与其他模型的连接

- 040 协方差与分散化
- 032 期望值

1. Top 1/5/10贡献多少结果？
2. 均值与中位数差多大？
3. 最大项失败损失多少？
4. 更多独立下注是否提高抓到赢家的概率？
