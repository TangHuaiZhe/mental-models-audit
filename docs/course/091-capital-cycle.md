# 第091讲：资本周期（Capital Cycle）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

行业高利润会吸引资本进入，新增资本形成供给并压低价格与ROIC；低回报又促使资本退出，形成周期。

## 核心机制

资本开支有延迟。景气高点企业同时扩产，几年后项目一起投产，可能导致供过于求；低谷停止投资后未来供给又收紧。

## 为什么它对公司与行业研究重要

特别适合半导体、电池、AI基础设施、航运和资源品，补足军备竞赛模型无法回答的‘投完以后行业回报率如何’。

## 典型应用

- AI算力高回报引发数据中心和芯片扩产
- 动力电池高景气引发全行业产能建设
- 存储芯片低谷缩减资本开支后供给改善

## 什么时候调用

- ROIC是否远高于资本成本？
- 新增CAPEX/产能有多大？
- 何时形成有效供给？
- 需求能否吸收新增供给？
- 低谷时谁会退出或停止扩产？

## 适用边界与常见误用

如果进入壁垒使新增资本无法形成有效供给，资本周期可能很弱；短期供需仍由043处理。
