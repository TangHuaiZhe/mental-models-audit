# 第091讲：资本周期（Capital Cycle）

> **Model Set v1.0**：本讲由跨行业 Regression Tests 引入/重构。GitHub 页面是当前 Audit Model Set 的发布版本；旧课程页面保留在 legacy URL 中。

## 一句话定义

行业高利润会吸引资本进入，新增资本形成供给并压低价格与ROIC；低回报又促使资本退出，形成周期。

## 一、起源与学科背景

资本周期分析来自产业经济学对进入、投资与竞争的研究，并被投资实践用于观察供给端。它强调利润信号引发资本进入，投资建设具有时滞，新增供给又改变未来回报。对具体行业的预测仍需结合需求和进入壁垒。

## 二、核心机制

高回报→融资与资本开支增加→建设时滞→产能投放→供给增加→价格/利用率/投入资本回报率承压→投资收缩与退出。关键不是“资本开支增加必然价格下跌”，而是**可交付有效供给**相对于需求增长的变化。应把宣布投资、实际付款、建设进度、良率爬坡和可销售产量分开。

## 三、经典案例：逐步拆解

**教学假设：存储芯片扩产。**景气期多家厂商宣布新厂；建设和调试需要时间，投产时若需求增速放缓，行业利用率和售价承压。低谷中取消新项目可能令未来供给增量减少。若技术代际切换使旧产能无法生产新产品，名义产能高也未必造成同一产品过剩。不要把教学路径误写成任何一家公司的实测结果。

## 四、跨领域迁移

**航运：**高运价推动订船，交船延迟带来同步供给；船龄和拆船影响退出。**数据中心：**宣布算力投资到实际可用容量受电力、机架和芯片交付限制；算力利用率还取决于需求与软件效率。两者共通的是投资时滞，瓶颈却不同。

## 五、何时调用与分析步骤

行业利润明显高于资本成本、扩产公告密集且投产有时滞时调用。建立项目级时间表：资本开支、预计有效产能、达产率、退出量与需求情景；计算未来供需缺口和资本回报敏感性。持续检查项目取消和技术替代。

## 六、边界、误用与反例

强进入壁垒、产能不可替代或需求同步加速时，扩产未必压低回报。反例：新增资本主要用于替换旧产能，净有效供给并未增加。043 描述当前供需价格；091 专门研究投资改变未来供给；066 解释竞争者为什么都要投入。

## 七、与其他模型的连接

[043 供需](043-supply-demand.md)判断当期价格；[066 军备竞赛](066-arms-race.md)解释共同投资动机；[073 延迟](073-delay.md)解释投资决策与投产间的时间错位。

## 八、五个关键自问

1. 当前回报相对资本成本有多高？
2. 宣布的资本开支有多少会变成净有效供给？
3. 新增产能何时、以何种良率投放？
4. 需求和退出能吸收多少新增供给？
5. 哪个项目取消或技术替代会推翻结论？

## 九、思考练习

假设行业现有有效产能 100，未来两年新产能 30、退出 10、需求由 95 增至 110。计算净产能及利用率；再做新产能仅实现一半的情景，解释为何不能只用公告资本开支下结论。

## 十、自测题

**题目：**某行业资本开支同比增长 50%，是否已确认未来供过于求？

**参考思路：**未确认。需知道基数、建设时滞、良率、替换产能、需求增长和退出；资本开支不是可销售供给。

## 十一、Evolution（版本演化）

先识别利润信号；再追踪项目到净有效供给；再建立需求和退出情景；最后检验未来 ROIC（投入资本回报率）。本次只扩充课程，不修改 Model Set v1.0。

## 研究与决策核对

**最小证据包：**项目级扩产公告、实际资本开支、建设进度、可销售产量、良率、旧产能退出、需求增长和行业投入资本回报率。资本开支是现金流，产能是未来存量，产量是当期流量，三者不能直接等同。按项目而不是只看行业总额建时间表，才能识别集中投产的年份。

**练习提示：**上文假设下，期末有效产能为 100＋30－10＝120，需求 110，利用率约 91.7%；若新增产能只实现一半，产能为 105，需求 110 可能无法完全满足。即使算出利用率，也还需结合成本曲线、库存和价格弹性才能推断 ROIC（投入资本回报率）。
