# Course Quality Rubric v1：课程质量量表

本量表用于审读 `config/model-registry.yaml` 中的现行课程页。模型身份、编号和调用语义仍以现有注册表与技能为准。正文可以教学化扩充，不能借写作改变模型边界。英语术语首次出现时附中文释义。

## 评分方法

每项按 0–2 分评分：0 为缺失，1 为提及但无法独立用于分析，2 为有解释、可复核例子或可执行问题。总分 20 分；建议 18 分及以上、且第 2、5、6、7 项均为 2 分，才称为教材级。字数只作差距信号，不作质量替代。

| 项目 | 2 分的可核查要求 |
| --- | --- |
| 1. 起源与学科背景 | 指出问题从何而来、相关学科和可查原始来源；不把后来的流行表述冒充最初定义。 |
| 2. 核心机制 | 明确变量、因果链、方向、必要条件；适用时给出量纲或简式。 |
| 3. 经典案例 | 给出可逐步解释机制的真实或明示为教学假设的案例，避免未经证实的数字。 |
| 4. 跨领域迁移 | 至少两个不同领域，逐一说明哪些变量映射相同、哪些条件不同。 |
| 5. 调用条件 | 指明可观察的触发信号、所需证据、分析步骤和退出条件。 |
| 6. 边界与反例 | 说明不适用情形、竞争解释及至少一个反例或可证伪观察。 |
| 7. 模型连接 | 至少两个相邻模型，说明职责分工，不用相似名字代替关系。 |
| 8. 五个自问 | 恰好五个，覆盖对象、机制、证据、反例与决策。 |
| 9. 练习与自测 | 给读者独立练习和带参考思路的自测，最好涉及计算或判别。 |
| 10. Evolution／版本演化 | 说明初学到熟练的使用路径，记录本次课程内容演化而不混淆 Model Set 版本。 |
