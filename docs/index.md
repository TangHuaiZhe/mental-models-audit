# 项目定位

这是一套以“建立跨学科思维工具箱”为目标的长期课程。重点不是记住100个名词，而是训练：识别问题、选择模型、跨领域迁移、组合模型、检验模型边界，并在现实决策中持续修正。

## 学习原则

1. **模型是地图，不是现实。** 每个模型都是有用但有限的简化。
2. **先理解机制，再记名称。** 重点解释模型为什么成立、在什么条件下成立。
3. **必须跨领域迁移。** 每讲至少覆盖三个场景，尽量包含投资/商业、历史/政治、个人生活。
4. **必须讲清边界。** 每个模型都要说明误用方式、反例和适用条件。
5. **以调用能力为目标。** 每讲包含识别信号、五个自问、自测和一个实践练习。
6. **组合优先于孤立。** 逐步建立模型之间的连接，而不是把100个模型变成100张互不相关的卡片。

## 课程总结构：100讲

课程分为十个模块，每个模块十讲。具体课程入口统一放在下方 **「课程目录」**，这里仅保留模块级地图：

3. **物理学与工程学（21—30）**

9. **博弈论、政治学与社会学（81—90）**
10. **历史、战略与决策（91—100）**

## 每讲的固定结构

- 一句话定义
- 起源与学科背景
- 核心机制：它为什么有效
- 典型案例：至少一个经典案例
- 跨学科迁移：投资/商业、历史/政治、个人生活等
- 何时调用：现实中的识别信号
- 适用边界与常见误用
- 与其他模型的连接
- 五个关键自问
- 思考练习与自测题
- Evolution：后续学习中如何修正和扩展

## 跨学科思维总览

值得重点训练的学科视角包括：物理学（规律、约束、守恒）、数学与统计学（概率、量化、不确定性）、生物学（演化、适应、生态）、计算机科学（抽象、分解、算法）、哲学（概念、逻辑、认识论）、经济学（激励、稀缺、机会成本）、心理学（认知偏差、动机）、历史学（路径依赖、偶然与结构）、社会学（个体与结构）、政治学（权力与制度）、系统科学（反馈、非线性、涌现）、博弈论（策略互动）、工程学（约束、可靠性）、控制论（目标与纠偏）、科学方法论（假设、证据、证伪）。
